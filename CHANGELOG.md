# Changelog

All notable changes to this project are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-11-15

### Added

- Opens FAST.com full screen, with 8 to 16 connections, a 60 to 120 second test, loaded latency during upload, and all metrics on by default.
- Ignores the remote's arrow and page keys, so the page does not scroll during a test.
- Stays on the speed test site: links to other sites do not open.
- Android TV launcher entry and banner, and a normal launcher entry for phones.
